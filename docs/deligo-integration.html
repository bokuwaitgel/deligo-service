1. Overview

Deligo Mapper is a delivery location-tracking and map-editing service. It sits between the core Deligo WFM platform and your external order-management service, bridging two integration directions:

  • Inbound (Part A) — Deligo Mapper calls your order service to pull order details (items, totals, customer info) and merges them into delivery responses seen by drivers, shops, and customers.
  • Outbound (Part B) — Deligo Mapper calls the Deligo external API (api.deligo.mn) to list a driver's sales orders, fetch order detail, and change order statuses on behalf of drivers.

Part A — Order Service Integration Contract

This section describes the HTTP contract your order service must implement so that Deligo Mapper can fetch order detail at runtime.

A.1 Configuration

Set the following environment variable in Deligo Mapper's .env:

ORDER_SERVICE_URL=https://your-order-service.example.com
No auth header is required from Deligo Mapper's side by default. Coordinate with the Deligo team if you need an API key or JWT on outgoing requests.

A.3 Get Multiple Orders (Batch)

POST  {ORDER_SERVICE_URL}/api/orders/batch

Called when building paginated list views (driver dashboard, shop dashboard). Batches all sales numbers in a single request instead of N individual calls.

Request Body

{
  "sales_numbers": [
    "26031012808A",
    "2603102D34A4",
    "2603102EED8C"
  ]
}

Success Response — 200 OK

Array of order objects in the same shape as the single-order response. Orders not found can be omitted.

[
  { "sales_number": "26031012808A", "total": "35000.000000", ... },
  { "sales_number": "2603102D34A4", "total": "35000.000000", ... }
]

Error Responses

StatusMeaning
404None found — treated as empty list
any otherDeligo logs a warning and returns deliveries without detail

Part B — Deligo External API Client

This section documents the outbound HTTP client that Deligo Mapper uses to communicate with api.deligo.mn.

B.1 Configuration

Environment VariableDefaultDescription
DELIGO_API_URLhttps://api.deligo.mnBase URL of the Deligo WFM API
DELIGO_API_EMAIL(none)Service-account email for login
DELIGO_API_PASSWORD(none)Service-account password for login
If DELIGO_API_EMAIL or DELIGO_API_PASSWORD are not set, all outbound Deligo API calls are skipped and a warning is logged.

B.2 Authentication & Token Cache

The client uses a Bearer JWT obtained from POST /api/user/login. The token is cached in memory and automatically refreshed 60 seconds before expiry.

Login Request

POST /api/user/login
Content-Type: application/json

{
  "email":    "service@example.com",
  "password": "••••••••"
}

// Response
{
  "access_token": "eyJ...",
  "expires_in":   3600
}

Token Refresh Strategy

  • On every outbound request the cached token expiry is checked.
  • If the token is still valid it is reused — no extra login call is made.
  • On HTTP 401, the token is invalidated and one immediate re-login is attempted.
  • HTTP timeout for all calls: 10 seconds.

B.4 Client Endpoints

List Driver Sales

POST  /api/sales/integration   |   Function: get_driver_sales(driver_id, offset, page_size)

ParameterDefaultDescription
driver_id—Driver's numeric ID (as string)
offset0Pagination offset
page_size50Items per page
 
// Request payload
{
  "criteria": {
    "es.driver_id": {
      "value":    "<driver_id>",
      "operator": "=",
      "dataType": "integer"
    }
  },
  "paging": { "offset": 0, "pageSize": 50 }
}

Returns [] on any error. The response data field may be an array or an object with an items/data key — both shapes are handled.

Get Sales Detail

POST  /api/sales/get   |   Function: get_sales_detail(sales_id)

The lookup key is sales_id (the numeric id field), not sales_number. Passing sales_number to this endpoint returns no data. 
// Request payload
{ "id": "<sales_id>" }

// Response (normalized by structure_sales_detail)
{
  ...raw fields...,
  "status_code":  "salesDelivery",
  "status_name":  "Хуваарилсан",
  "is_closed":    0,
  "order_items": [
    { "item_id": "123", "name": "Item A", "image_url": "...", "quantity": 1, "price": 5000.0 }
  ]
}

order_items normalization

The following raw field aliases are accepted and mapped to the canonical shape:

Canonical FieldAccepted Raw Keys (first match wins)
item_idsales_detail_id, item_id
nameitem_name, main_item_name, name
image_urldefault_image, image_url
quantitysales_qty, quantity
priceunit_price, line_total_amount, line_total_price, price

Change Sales Status

POST  /api/sales/changestatus   |   Function: change_sales_status(sales_id, status_id, driver_token?) 

// Request payload
{ "id": "<sales_id>", "statusId": <status_id> }
ParameterDescription
sales_idThe id field of the sales order
status_idTarget WFM status ID (see Section B.3)
driver_tokenOptional — if provided, uses the driver's own Deligo JWT instead of the service-account token

Returns True on HTTP 200, False otherwise. When called with a driver_token, a retry with the service-account token is not performed on failure.

5. Security Notes

  • Credentials (DELIGO_API_EMAIL, DELIGO_API_PASSWORD) must be stored as environment variables or secrets — never hardcoded or committed to source control.
  • ORDER_SERVICE_URL should point to an internal network endpoint where possible to avoid exposing order data over the public internet.
  • If an API key or token is required for Deligo Mapper to call your order service, use a fixed header (e.g. x-api-key) configured via environment variable.
  • HTTP timeout on all outbound calls is capped at 10 seconds to prevent cascading latency.
  • Driver tokens forwarded to /api/sales/changestatus are not stored and are only used for the duration of the single request.

6. Contact & Next Steps

Coordinate with the Deligo team on the following open items:

  1. Auth strategy — API key, JWT, or internal-network-only for the order service callback endpoints.
  2. Batch endpoint feasibility — whether POST /api/orders/batch can be implemented or if individual calls are preferred.
  3. Pagination — handling large order counts in the batch endpoint.
  4. Env-var handoff — sharing DELIGO_API_EMAIL / DELIGO_API_PASSWORD service-account credentials securely.
